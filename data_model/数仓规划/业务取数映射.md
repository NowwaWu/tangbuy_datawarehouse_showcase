### 3. 订单统计常用聚合

```sql
-- 按用户统计订单
SELECT usr_id,
    COUNT(DISTINCT tb_item_id) AS ord_cnt,                                       -- 订购商品数（去重）
    COUNT(DISTINCT CASE WHEN ord_line_stat IN (3,4,5,6,10) THEN tb_item_id END) AS paid_cnt,  -- 已支付
    COUNT(DISTINCT CASE WHEN ord_line_stat IN (1,2) THEN tb_item_id END) AS pend_cnt          -- 待下单
FROM dwd_trd_ds_ord_line_df
WHERE ds = '${bizdate}' AND is_del = 0
GROUP BY usr_id;
```

## 八、已知陷阱

### 1. 字段值不再兜底

所有 DIM/DWD/DWS/ADS 表 **不再使用 NVL/COALESCE 填充默认值**（0/-99/'未知'），缺失字段保留 NULL。
- 下游查询根据需要自行 `NVL` 或 `NULLIF`
- `COUNT(DISTINCT)` 不会被 '未知' 干扰

### 2. 店铺和商品 ID 前缀规则

| 前缀 | 含义 | 示例字段 |
|------|------|----------|
| `tb_` | TangBuy 平台自有商品、店铺、SKU | `tb_item_id`, `tb_shop_id`, `tb_sku_id` |
| `out_` | Shopify、TikTok、WooCommerce 等三方平台对象 | `out_shop_id`, `out_shop_nm`, `out_item_id` |
| `splr_` | 1688 等上游供应商对象 | `splr_item_id`, `splr_shop_id` |

> 新增或取数字段时不要再用裸 `item_id` / `shop_id` 表达公共字段。少量非 DS 或原生链路字段如 `dim_wh_shop_df.shop_id`、`item_src_id` 仍按当前表结构保留，跨表关联前先确认业务含义。

### 3. ODS 表 JOIN 需去重

ODS 表（`_ri` 后缀）可能有多条记录。JOIN 时用 ROW_NUMBER 取 rn=1，否则数据膨胀。参考 `dim_usr_info_df.etl.sql` 中的 `pmt_acty` CTE。

### 4. dim_comm_ip_geo_df 有重复

`dim_comm_ip_geo_df` 同一 IP 可能存在多条记录。JOIN 前需 GROUP BY：
```sql
ip_geo AS (
    SELECT register_ip, MAX(cntry_cd) AS cntry_cd, MAX(prov) AS prov, MAX(city) AS city
    FROM dim_comm_ip_geo_df
    GROUP BY register_ip
)
```

### 5. 分区字段统一为 `ds`，格式 `yyyyMMdd`

所有 DIM/DWD/DWS/ADS 表均使用 `ds STRING COMMENT '分区日期 yyyyMMdd'`。
