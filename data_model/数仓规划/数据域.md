英文缩写,英文名称,中文名称,备注
trd,Trade,交易域,DS平台核心业务流程：Draft下单 → 支付 → 履约发货 → 售后（退款/退货/换货）→ 订单完成。涵盖代发(dropship)和直购两种订单类型
itm,Item,商品域,DS选品与刊登全链路：三方商品采集/搜品 → 草稿箱 → 刊登到外部店铺（Shopify/TikTok/WooCommerce）。涵盖货盘、大店商品、类目、标签、定价模板、邮限、商品关联映射
wh,Warehouse,仓储履约域,DS包裹履约全流程：入库 → 称重 → 拍照 → 打包 → 物流发货 → 退包处理。涵盖仓库管理、增值服务、发票、申报、临时库操作。此域是DS业务的履约引擎
pay,Payment,支付结算域,DS资金全生命周期：用户充值 → 支付（订单/包裹补款）→ 退款 → 提现。涵盖账单、钱包、汇率、手续费、风控黑名单、欠款管理、PayPal特殊处理
usr,User,用户域,DS平台用户体系：注册/登录认证 → 会员等级与成长值 → 积分 → 收货地址管理 → 购物车 → 商品/店铺收藏 → 站内信。涵盖OAuth授权、设备标识、水印配置
store,Store,店铺域,DS多平台店铺管理：Shopify / TikTok / WooCommerce 店铺授权、履约服务配置、店铺状态管理。连接用户与外部销售平台
dist,Distribution,分销域,DS联盟推广体系：推广者(CPS)注册 → 代理等级 → 推广商品 → 佣金结算 → 提现。涵盖商务合作客户、推广惩罚、举报投诉、网红管理
comm,Common,公共域,跨域共享的基础设施：站内消息配置与记录、业务操作日志、异常消息记录。不直接参与核心业务过程但为各域提供支撑
